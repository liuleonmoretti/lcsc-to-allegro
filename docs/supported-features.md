# 支持范围与限制

[返回首页](../README.md)

以下描述对应程序 `0.2.0`。检查以实际输入和运行结果为准，不承诺所有立创器件均可转换。

| 类型 | 当前范围 |
| --- | --- |
| 输入 | 立创 C 编号获取的封装、本地 KiCad `.kicad_mod` |
| SMD | 当前支持范围内的顶层贴片焊盘 |
| 通孔 | 圆孔、镀通孔；检查孔径和镀孔属性 |
| 焊盘形状 | 矩形、方形、圆形、椭圆/长圆，仍须满足具体类型和层定义检查 |
| 角度 | 支持的正交旋转；任意角度不作近似转换 |
| 图形 | 支持层上的实线、矩形、圆等明确支持的轮廓 |
| 引脚编号 | 保留词法身份，允许满足约束的数字及大写 ASCII 标识；拒绝重复或不明确的编号 |
| 输出 | Allegro 16.6 原生 `.pad/.dra/.psm`、任务日志和验证记录 |
| 本地库 | 经验证与人工核对后发布到指定路径 |

## 明确不承诺支持

- 圆角矩形、自定义或其他复杂焊盘，不会静默近似成普通矩形。
- 槽孔、偏心钻孔、非镀通孔、未支持的焊盘层组合。
- 任意角度、未知物理几何、未知掩膜或锡膏规则。
- 超出已实现范围的填充、虚线或曲线图形。
- OrCAD Capture 符号、`.olb` 库、整板 PCB 转换及整板设计检查。
- 3D 模型转换、与任意新版本上游格式的自动兼容。

程序对未知或含混的输入倾向于失败，并保留失败证据。不要删除验证条件后把生成文件视为有效结果。

## 数据来源与验证边界

普通 C 编号路径检查上游数据与转换结果的一致性；三个可选厂家规则按指定图纸进行显式修正，两者不能混为“完全忠实于原始封装”。

厂家规则所依赖的 PDF 不随仓库分发。旧教程中出现的某个 C 编号不能视为当前支持清单；例如旧版示例 `C17414` 的上游锡膏几何已超出当前支持范围，不应用作默认快速开始示例。

原生验证通过不等于该器件符合全部焊接工艺或生产要求。还要检查封装型号、厂家推荐焊盘、器件方向、引脚定义、装配间隙和项目工艺。
