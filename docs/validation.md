## 用户如何核对

1. 运行 `./test.ps1`，检查公开包测试子集。
2. 按 [安装指南](installation.md) 设置本机 Cadence，运行 `doctor`。
3. 对自己的封装执行 `convert`，保存 `job` 路径。
4. 对同一任务执行独立 `verify`，检查输出和保留证据。
5. 人工对照器件图纸、引脚定义和工艺，再发布到本地库。

原生检查包括文件及参数一致性、引脚和焊盘读回、阻焊/锡膏/钻孔与原生日志等；详细实现见源码。项目不宣称完成了完整生产工艺认证或整板 DRC。
